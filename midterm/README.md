## 주제: 요리 할래말래

‘요리 할래말래’는 먹고 싶은 메뉴와 보유 재료를 바탕으로 직접 요리와 배달의 비용·시간을 비교하고, 상황에 맞는 식사 선택을 돕는 서비스 구상입니다.

공모전 준비 과정에서 발전시킨 아이디어를 이번 중간고사 대체 과제의 사업 구상 주제로 연결하여, 서비스 시연 화면과 영상·보고서로 구체화하고 있습니다.

## 과제 구성

- **모션그래픽 영상:** 서비스의 비용·시간 비교 방식과 사업 실행 계획을 설명합니다.
- **AI 영화:** 일상 속에서 요리와 배달을 고민하고 선택하는 과정을 이야기로 보여줍니다.
- **사업 및 제작 보고서:** 사업 구상의 이유·내용·계획·절차와 두 영상의 제작 과정을 정리합니다.

## 관련 제작 자료

- 서비스 시연 HTML
- 영상 콘티 및 제작 프롬프트
- 제작 과정과 수정 기록
