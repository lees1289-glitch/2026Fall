# 오늘은, 요리 할래말래? — AI 영화 콘티 v5 (90초, 대사 없음)

기준일 2026-10-20 / 제출 정리 2026-10-21 · 16:9 · 1920×1080 · 24fps · H.264 + AAC 스테레오

## 한 줄 요약
같은 저녁, 한 청년이 배달 가격 앞에서 멈추고 → 서비스로 요리와 배달을 비교해 요리를 고르고 → 남은 재료를 다음 끼니로 잇고 → 피곤한 날에는 배달을 고른다. **영화는 "왜 이런 서비스가 필요한가"를 말없이 보여 주고, 숫자와 계산은 모션그래픽이 설명한다.**

## 고정 설정
- **인물**: 가상의 20대 중반 한국 남성, 짧은 검은 머리. 같은 인물·같은 방 참조 이미지를 모든 AI 컷에 사용한다.
- **의상**: 회색 후드 + 차콜 바지(S1~S11) / 남색 티셔츠(S12, 다음 날) / 검은 재킷 + 백팩(S13, 며칠 뒤)
- **방**: 왼쪽 침대, 중앙 낮은 오크 테이블, 오른쪽 주방과 냉장고. 보유 설정: 고추장·간장·설탕·밥·식용유·소금.
- **색**: 민트 #15B8A7, 짙은 녹색 #17373D, 배경 #F5F7F2, 노랑 #F1C765. UI 화면과 타이틀은 모션그래픽과 같은 디자인.
- **화면 문구**: 모든 UI에 "비공식 사업 제안 · 화면과 수치는 시연 예시".

## 흐름이 말하는 것 (대사 없이 전달되는 방식)
1. S1–S3: 먹고 싶다 → 배달은 비싸다 → 요리하려니 재료가 없다.
2. S4–S7: 서비스로 비교 → 요리를 선택. (여기까지가 "왜 필요한가"의 해답)
3. S8–S11: 재료 도착 → 요리 → 식사 → 남은 재료를 직접 확인.
4. S12–S14: 다음 한 끼로 연결 → 피곤한 날은 배달도 정답.
5. S15: 서비스 이름과 한 줄 설명.

## 편집·제작 메모
- **한글과 숫자는 모두 편집 레이어**로 만든다. AI 생성 영상에 글자를 넣지 않는다.
- UI 화면은 모션그래픽과 같은 디자인·계산으로 새로 만든다. **새로 필요한 화면**: S2 가상 배달 결제 카드(상표 없음), S7 비교 카드, S14 마라탕 추천 카드.
- 제육 보관 한 몫(S10)은 S12와 S13 사이에 먹은 것으로 처리한다. "며칠 뒤"가 그 시간을 덮는다. 세 끼를 모두 보여 줄 필요는 없다.
- 영상에서 말하지 않는 가정은 화면 하단 문구 또는 보고서에 기록한다: 장보기 배송비 0원, 기존 재료의 과거 비용 제외, 시간은 설거지 제외, 요리 35분 = 장보기 대기 20분 + 조리 15분.
- 서비스는 "비교와 선택을 돕는 구상"이며 실제 가격 수집·주문·결제·AI 추천 운영을 구현한 것이 아니다. 영화 어디에서도 그렇게 표현하지 않는다.
- 음악·효과음은 영화 전체를 합성해 직접 만들 수 있다(사용권 문제 없음). 인물 영상만 Higgsfield에서 생성한다.

## 제작 순서 (비용을 아끼는 순서)
1. **참조 이미지 먼저**: 인물과 방의 정지 이미지를 만들어 승인한다(02 파일의 R1~R3).
2. 승인된 이미지를 넣어 **컷 하나씩 짧게 생성**하고, 얼굴·방이 이어지는지 확인한다.
3. 생성한 클립을 이 콘티의 시간 순서대로 파일 이름만 붙여 주시면(`S01.mp4`처럼), 편집·UI·소리를 얹어 90초 영화로 합친다.
4. 실패한 컷은 해당 프롬프트만 고쳐 다시 생성한다.
