## 사업 구상 프로젝트: 요리 할래말래

‘요리 할래말래’는 먹고 싶은 메뉴와 보유 재료를 바탕으로 직접 요리와 배달의 비용·시간을 비교하고, 상황에 맞는 식사 선택을 돕는 서비스 구상입니다.

공모전 준비 과정에서 발전시킨 아이디어를 수업의 사업 구상 과제로 연결하여, 서비스 시연 화면과 영상·보고서로 구체화하고 있습니다.

### 과제 자료

- 모션그래픽 영상
